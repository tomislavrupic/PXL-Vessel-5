# PXL Vessel-5 / Pixel Records

Static GitHub Pages product site for the Vessel-5 Audio Unit and standalone app. The screenshots show the actual native UI. First Flight is an original 46-second performance rendered with three instances of the 0.2.4 AU, with shared final gain and fades. The waveform is derived from that audio; four short comparisons were rendered from the 0.2.2 AU. The package link points to the 0.2.4 release. No external runtime dependencies, trackers or accounts are used.

The promotional banner is original artwork, used as the page’s Open Graph and X sharing image; the instrument screenshot remains an actual product capture.
